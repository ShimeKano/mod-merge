Cách khắc phục theo lỗi

  1. Trang 404 / không tìm thấy site: vào Repository → Settings → Pages. Nếu chọn Deploy from a branch, đặt Branch = main, Folder = /(root). Xác nhận index.html nằm ở thư mục gốc. Đợi deploy hoàn tất trong Actions.
  2. Trang trắng hoặc thiếu giao diện: nhấn Ctrl + F5, thử cửa sổ ẩn danh, tắt extension chặn script và kiểm tra styles.css / app.js có tải được không.
  3. ZIP không hoạt động: cho phép truy cập CDN hoặc kiểm tra mạng. Ứng dụng thử tải JSZip từ jsDelivr rồi chuyển sang cdnjs.
  4. File không đọc được: dùng file JAR/ZIP/ MCPACK hợp lệ; file pack Bedrock phải có manifest.json ở thư mục gốc của archive.
  5. Vẫn lỗi: sao chép báo cáo bên trên và gửi kèm ảnh màn hình Console (F12 → Console). Không gửi file mod riêng tư nếu không cần thiết.
