MINECRAFT MOD TOOLKIT

Gộp mod.
Gọn bộ cài.

Đóng gói mod Java, gộp pack Bedrock và kiểm tra khả năng tương thích. File của bạn được xử lý cục bộ trong trình duyệt.

01 / JAVA EDITION

Đóng gói nhiều mod PC

Chọn các file .jar cùng loader và phiên bản Minecraft.

.JAR → .ZIP

Chưa có mod nào được chọn.

Kết quả là ZIP chứa các JAR riêng trong thư mục mods/, không phải một JAR bytecode đã hợp nhất.

02 / BEDROCK EDITION

Gộp các addon / pack

Chỉ gộp các pack cùng loại để hạn chế hỏng cấu trúc.

.MCPACK

Chưa có pack nào được chọn.

Behavior và Resource pack cần được gộp riêng.

Bản MVP không tự sửa mọi identifier, script API hay dependency tham chiếu giữa các pack. Hãy sao lưu và thử trong world mới.

03 / COMPATIBILITY

Chuyển đổi mod?

Kiểm tra giới hạn kỹ thuật trước khi thử chuyển đổi.

INFO
Java → Bedrock

Không thể chuyển mã Java mod thành addon Bedrock chỉ bằng đổi đuôi. Gameplay phải được viết lại bằng Bedrock Script API / components.

Forge ↔ Fabric

Không có bộ chuyển đổi tổng quát đáng tin cậy. Mod cần source code và phải port sang API của loader đích.

Resource / texture

Một phần texture, ngôn ngữ và model có thể trích xuất hoặc chuyển cấu trúc, nhưng vẫn cần ánh xạ và kiểm thử thủ công.

ModMerge tập trung vào những thao tác có thể tự động hóa an toàn. Công cụ sẽ không giả vờ chuyển đổi thành công khi nội dung thực tế không tương thích.
