01 / JAVA EDITION

Đóng gói nhiều mod PC

.JAR → .ZIP

Chưa có mod nào được chọn.

ZIP chứa các JAR riêng trong thư mục mods/. Đây không phải một JAR đã hợp nhất bytecode.

02 / BEDROCK EDITION

Gộp các addon / pack

Chỉ gộp các pack cùng loại để hạn chế hỏng cấu trúc.

.MCPACK

Chưa có pack nào được chọn.

Behavior và Resource pack cần được gộp riêng.

Bản thử nghiệm chưa tự sửa mọi identifier, script API hay dependency. Hãy sao lưu và thử trong world mới.

03 / COMPATIBILITY

Chuyển đổi mod?

Kiểm tra giới hạn kỹ thuật trước khi thử chuyển đổi.

INFO
Java → Bedrock

Gameplay Java phải được viết lại bằng Bedrock Script API / components; đổi đuôi file không thể chuyển mã.

Forge ↔ Fabric

Không có bộ chuyển đổi tổng quát đáng tin cậy. Mod cần source code và port sang API loader đích.

Resource / texture

Một phần texture, ngôn ngữ và model có thể trích xuất hoặc chuyển cấu trúc, nhưng vẫn cần ánh xạ và kiểm thử.

ModMerge chỉ thực hiện thao tác có thể tự động hóa tương đối an toàn; không báo chuyển đổi thành công giả.
